# Movie Night Picker 🍿

Can't agree on what to watch? Add the films you're considering, choose a genre and a maximum length, and let the picker decide for you.

Built by [CineVault8](https://cinevault8.blogspot.com/)

## Features

- Add films with title, genre and runtime
- Filter by genre and maximum length (90 minutes, 2 hours, 2.5 hours or any)
- Random pick that avoids repeating the last choice
- Remove films from your list
- No installation, build step or server required

## Demo

Open `index.html` in your browser to try it locally, or enable GitHub Pages (see below) to get a live link.

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in any modern browser.
3. Add a few films, then press **Pick a movie**.

## Enable GitHub Pages (Optional)

1. Go to **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and the `/ (root)` folder, then click **Save**.
4. After a minute or two, your demo will be available at `https://rasta212.github.io/movie-night-picker/`.

## Limitations

This is a demo. Your list is stored in the browser's local storage, so it is not synced between devices or users.
